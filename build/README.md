# Scoped Foundation compatibility build

Run an explicit PHP 7.4 or newer binary with `-d phar.readonly=0 build/foundation/build.php` from this repository. The builder packages `foundation/source/` and `foundation/stub.php`, verifies all expected members by name, preserves the original SHA-256 signature algorithm and stored member modes, replaces only `low_random/low_random.phar`, and refreshes the active test source inventory.

This is the add-on-local form of the established `packettide/tools` Foundation build (`foundation/phar.php` and the `gulp foundation` template substitutions). All 22 original Foundation 4.10 members matched tools commit `cc1d34bd8db0119bbe2b9e38ebb337add61c7fbb` exactly after the documented substitutions and insertion of the original generated licensing JavaScript. `foundation/provenance.json` records those original bytes, source templates, archive metadata and actual stored permission bits. The licensing constant remains `true`. Shared tools are unchanged.

The committed stub is the original generated extraction stub with scoped compatibility repairs and its exact byte length recalculated. Native build timestamps vary; binary hashes across separate builds need not match. Member payloads, modes, signature algorithm, alias, compression and metadata are the preservation checks. Tests execute the shipped archive and separately rebuild a complete owned copy on each runtime.

The additional `FluxCapacitor/Conduit/NativeSettings.php` member is a local callback factory with mode0644, declared separately from the original22 members in provenance. Existing GFS, bridge and cache methods execute those same parser bodies without adding methods to extensible legacy classes. Newly introduced native operations bind global builtins; original namespaced base64/unserialize dispatch remains intact. This preserves legal PHP7.4 child declarations. Known native callback handler-state and raw parser blockers remain unresolved; this build is not a completed compatibility release.

Original caller-local carrier and decoder hooks now run before native-only normalization, including Bridge-specific namespaces and raw/null inputs. Their original `@base64_decode` / `@unserialize` reporting context is retained from the baseline expressions; strict tests still detect diagnostics under those original operators. Raw cache decoding retains its original unsuppressed hook. The native helper itself binds global primitives and has no caller hook authority. Native Stringable carriers convert once. Callback handler-stack/mask preservation inside the native parser remains blocked.

The inventory publication refuses preexisting symlink/hardlink targets before building and atomically replaces its original regular file after validating its identity. Fresh complete build copies include the tracked inventory. The extraction cleanup retains its original caller-directory restoration when removing a linked root.

The compatibility harness instruments actual executable CLI code while preserving script argv, namespace/declaration placement and source identity. Every native child retains its actual status, full stream hashes/bytes, strict startup receipt and diagnostic journal before test teardown. The checked parent rejects ignored child failures, stderr, deadlines, missing startups and mismatched runtime flags. Four existing authored test-tool negative controls are bound explicitly to their caller/command/input hashes and complete expected outcomes in `tests/Support/native-control-profiles.json`; this grants no exception for production diagnostics. Rebinding requires a deliberate reviewed edit. The duplicate coverage-reservation control now catches only its exact owned tooling exception and emits a finite controlled status/message, preserving its reservation/report assertions.

Both executions retain their complete outcomes and have individual execution deadlines; selected configuration file hashes are checked before and after the file child. Inline code retains PHP's native behavior of ignoring a prepend. Required diagnostic settings apply last in the executable option region without changing script arguments.

New native source regressions cover canonical decoded Stringable frame/value, pinned PHPUnit static restoration, original raw setter arguments and argument/container destruction order, NAN settings and completed persistence before destructor failure.
