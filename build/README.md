# Scoped Foundation compatibility build

Run an explicit PHP 7.4 or newer binary with `-d phar.readonly=0 build/foundation/build.php` from this repository. The builder packages `foundation/source/` and `foundation/stub.php`, verifies all expected members by name, preserves the original SHA-256 signature algorithm and stored member modes, replaces only `low_random/low_random.phar`, and refreshes the active test source inventory.

This is the add-on-local form of the established `packettide/tools` Foundation build (`foundation/phar.php` and the `gulp foundation` template substitutions). All 22 original Foundation 4.10 members matched tools commit `cc1d34bd8db0119bbe2b9e38ebb337add61c7fbb` exactly after the documented substitutions and insertion of the original generated licensing JavaScript. `foundation/provenance.json` records those original bytes, source templates, archive metadata and actual stored permission bits. The licensing constant remains `true`. Shared tools are unchanged.

The committed stub is the original generated extraction stub with scoped compatibility repairs and its exact byte length recalculated. Native build timestamps vary; binary hashes across separate builds need not match. Member payloads, modes, signature algorithm, alias, compression and metadata are the preservation checks. Tests execute the shipped archive and separately rebuild a complete owned copy on each runtime.

The additional `FluxCapacitor/Conduit/NativeSettings.php` member is a stateless byte normalizer with mode0644, declared separately from the original22 members in provenance. It is adapted from the independently reviewed Transcribe pure-wire helper (owner05 integration/owner10 algorithm). Legacy escaped strings and complete first-value prefixes are rewritten before native hydration in each original caller. No temporary parser error handler or new methods on extensible legacy classes are introduced. Newly introduced operations bind global builtins; original namespaced base64/unserialize dispatch remains intact. This preserves legal PHP7.4 child declarations.

Original caller-local carrier and decoder hooks run before native-only normalization, including Bridge-specific namespaces, raw/null inputs and reference-returning helper values. Each selected path retains the original `@base64_decode` / `@unserialize` scopes; native conversion and hydration execute in their original caller frames. The byte helper does not convert opaque operands or install a global handler. A settings-only guard maps a primitive string with an unrecognized initial native opcode to the existing false/empty fallback before any hydration can occur. Recognized malformed frames remain native diagnostics, and raw cache decoding retains its unsuppressed diagnostic contract.

The inventory publication refuses preexisting symlink/hardlink targets before building and atomically replaces its original regular file after validating its identity. Fresh complete build copies include the tracked inventory. The extraction cleanup retains its original caller-directory restoration when removing a linked root.

The compatibility harness instruments actual executable CLI code while preserving script argv, namespace/declaration placement and source identity. Every native child retains its actual status, full stream hashes/bytes, strict startup receipt and diagnostic journal before test teardown. Inline code retains PHP's native behavior of ignoring a prepend. Required diagnostic settings apply last in the executable option region without changing script arguments.
