Low Random for ExpressionEngine

Low Random selects a random file, list item, letter or number for use in your templates.

Compatibility

The current package declares ExpressionEngine 3 or later. The changelog records the EE5/EE6 update and verified EE7 compatibility. Use the package intended for your installed ExpressionEngine release and follow that release’s server requirements.

Historical versions remain available on GitHub for EE2 and EE1. Those are separate from the current package.

Installation

  1. Download and unzip the Low Random package.
  2. Copy the low_random folder into your site’s system/user/addons/ directory.
  3. In the ExpressionEngine control panel, open Add-On Manager and install Low Random.
  4. Continue to the Tag Reference for the five existing template tags.
